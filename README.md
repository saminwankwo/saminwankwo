### 🔌 SocketDocs

**[SocketDocs](https://github.com/saminwankwo/socketdocs)**

OpenAPI-inspired documentation and validation tooling for **WebSocket APIs**.

The goal is to bring the familiar developer experience of Swagger/OpenAPI to real-time applications.

* 📖 Interactive WebSocket API documentation
* ✅ Runtime request/response validation
* 📋 Contract-first API definitions
* 🧩 Zod & JSON Schema support
* 🔌 Socket.IO, WebSocket, and framework integrations
* 🧪 Automated testing support
* 🚀 SDK generation roadmap for TypeScript, Go, Python, and PHP

```bash
npm install @socketdocs/core
```

### 🚨 Telegram Error Logger

**[telegram-error-logger](https://github.com/saminwankwo/telegram-error-logger)**

A lightweight Node.js error and server monitoring package that sends production alerts directly to Telegram.

Designed for developers who want immediate visibility into application failures and infrastructure issues without introducing a heavy monitoring stack.

* 💥 `uncaughtException` & `unhandledRejection`
* 🧠 Heap and memory monitoring
* ⚙️ CPU usage monitoring
* ⏱️ Event-loop lag detection
* 🔎 Request context with `AsyncLocalStorage`
* 📋 Request metadata and user context
* 🚦 DEBUG, INFO, WARN, ERROR & CRITICAL levels
* 📦 Zero runtime dependencies
* 🌐 Native `fetch` support for Node.js 18+

```bash
npm install telegram-error-logger
```
