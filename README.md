- ⚙️ Backend engineer with **5+ years in Node.js (NestJS, Express)** and **7+ years in PHP / Laravel**
- 🏗️ I design scalable **microservices**, secure **REST & GraphQL APIs**, and multi-tenant SaaS platforms
- 🚀 I ship with **Docker**, **GitHub Actions**, and **AWS**, including zero-downtime deployments
- 💳 Worked across fintech, e-commerce, healthtech, and EdTech (Stripe, Paystack, webhooks, split payments)
- 📦 I publish open-source tools on npm
- 🎓 I mentor developers and have led a backend training program for 12+ engineers
- 💬 Ask me about: NestJS, API security, microservices, authentication, CI/CD
